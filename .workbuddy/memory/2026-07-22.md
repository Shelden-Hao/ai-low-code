## CI/CD 集成

### 新增文件
- .github/workflows/ci.yml — GitHub Actions CI 工作流
- docker-compose.ci.yml — 本地测试用 docker compose（postgres + redis）

### CI 工作流流程
1. 触发：push 到 main/develop 或 PR
2. 启动 PostgreSQL + Redis（GitHub Actions services）
3. 安装后端依赖 → Prisma 推表 → seed 数据
4. 启动后端 NestJS 开发服务器
5. 运行后端 Jest E2E 测试（47 用例）
6. 安装前端依赖 → Playwright Chromium
7. 启动前端 Vite 开发服务器
8. 运行 Playwright E2E 测试（11 用例）
9. 失败时上传测试报告 artifact（保留 7 天）
